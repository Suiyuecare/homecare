## 每次接續方式

先讀 BUILD_STATE.md、PRODUCT.md、docs/API.md、BUILD_BACKLOG.json、此清單、APM_CIS_SSO_SCOPE.md 及私人 GitHub HANDOFF，再讀實際程式。沿已存在的 ui.js、records/history、角色與機構隔離及服務核閱快照；保留未提交資料。優先完成完整流程而非只增加入口或查看畫面；工作包可分開並行，但共用model/index由整合者維護。

測試僅使用合成資料、隔離資料庫及隨機loopback，不讀正式帳號資料、真實個資或4310私人服務。保留每次失敗及實際exit code；修正後執行受影響檢查，不把未重新執行的全套命令宣稱成通過。每次把本機完成與原平台對等、正式部署及真實營運驗收分開記錄。

未知規則不阻擋可獨立安全完成的介面、保存、參數及離線驗證框架；正式計算/申报/支付/法定資格必須取得其核定依據。不得自行購買主機、正式部署、發送外部訊息或正式申報付款。只有完成可操作里程碑、失敗或需要關鍵資料時通知使用者。

# 群組總覽逐機構帳號停用守門

這是既有總覽的授權修正，不新增集團角色、跨機構分享、主身分合併或去重分母。既有八項紀錄筆數、開始日／月份、來源 fingerprint、CSV、列印和 Portal 單一機構限制保持。

舊總覽只確認所選機構的 membership.role 為 admin；另一機構的帳號被明確停用後仍保留 admin membership，重新登入目前有效機構可直接查到該已停用機構。合成 memory 的原始重現原生退出 1，完整證據保留；沒有讀取私人資料庫或正式身分。

目前機構及每個選取機構都必須是現存 admin membership，且通過既有 accountMembershipActive。這個 helper 查驗原帳號生命週期的目前列、不可變 head、連續版次與 membership 一致性；明確 suspended 拒絕整份讀取，未知或壞 head 也停止，不返回其餘機構的部分資料、不修補保存資料。沒有生命週期紀錄仍沿既有核定的 active baseline，不新增其他例外。當前機構有效 session 不代替其他機構授權。

`GET /api/group-overview`、CSV 與單機構來源追查均沿同一 guard；在資料快照內再檢查全部選取機構。停用／復職沿既有帳號變更撤銷 session，測試明確重新登入仍有效的目前機構，再直接嘗試已停用的選取機構。明確復職並重新登入後，原授權機構可再次查詢。沒有改寫個案或目前已核閱數字。

Node 22.23.2 及 Node 24.19.0 的群組 pure、真 HTTP 與既有 DTO 測試，各 37 項原生退出 0，無跳過。涵蓋選取機構停用仍保留 admin、目前機構停用、復職、舊 session 撤除、JSON／CSV／既有 fingerprint 明細拒絕、未知狀態、壞 JSON、目前 head 不一致和 unsafe SQL 版次；保存各表與 total_changes 逐次確認讀取零寫入。unsafe SQL 版次沿既有 SQLite／伺服器錯誤路徑拒絕，不被當作有效帳號。

瀏覽器候選增加停用後 fresh 列印／CSV、延遲 403 不產生列／blob／列印、明確復職，以及未知生命週期 head 的 409。必須等整合來源凍結後執行，結果另以實際原生退出碼、來源 SHA、PNG 視檢記錄；本文件尚不宣稱該候選已通過瀏覽器或整套回歸。

撤權驗收針對伺服器重新讀取時的現有授權與已取消的介面 owner。已在撤權前合法傳出的資料無法透過這個守門追回，未新增輪詢、推播或遠端抹除政策。CP08 正式跨機構自然人去重、遮罩、分享和下載矩陣仍待核定，這次不實作人工 link，也不把尚未核對的同名個案視作同一人。

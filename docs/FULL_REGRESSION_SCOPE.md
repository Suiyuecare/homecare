# 0.78 全系統回歸與修正

本輪以工廠合成資料、記憶體／暫存資料庫與隨機本機連接埠，執行全部 90 個已配置命令。範圍包含個案、員工、計畫、排班、服務核閱、人工費薪、表單、附件、歷程、報表、內部提示、問卷、Portal／APM 與合成還原。正式帳號、私人資料庫及正式公司登入不屬於合成測試。

修正五類程式問題：

- 請求讀取資料期間若角色、機構權限或本人綁定已失效，寫入仍可能沿用先前授權。現在於資料讀取完成後重新確認身份、權限、CSRF 與請求來源；真 HTTP 測試驗證拒絕與零後續寫入。
- 忙碌按鈕的文字轉場造成舊標籤與「處理中」重疊。保留焦點、尺寸與一般／減少動態，三種按鈕於前五個畫面更新均只顯示忙碌標籤。
- 無互動的狀態通知攔截下方滑鼠與觸控。通知持續使用 aria-live，點擊可穿透至原操作。
- 列印報表最後一頁露出螢幕底色。紙本根畫布改為白色，螢幕 APM 配色保持；七種實際 PDF 仍驗完整文字、重複表頭與安全邊界。
- 同機構其他舊個案的非文字姓名／空編號，使人工接觸足跡無法開啟。只使用個案共用的安全文字投影作為選項；識別碼、機構、重複及完整分頁檢查保持，原資料和歷程不變。

測試修正包含財務 CSV 與慢回應攔截的查詢模式同步、PDF 外部工具的可配置路徑，以及合成來源副本納入必要的忽略規則／範例設定。保留原失敗與真實退出碼，未放寬業務斷言或個別測試時間限制。

完整程式測試 2,060 項通過。全部90個已配置命令均取得原生退出碼0的完整覆蓋；修正後重測取代對應失敗，原始失敗仍保留。CI 以 Node 22.13／24 各驗完整程式測試，六組恰好一次涵蓋剩餘全部配置；合成加密演練的臨時口令只經 stdin，不存放或發布秘密。GitHub 結果以相同提交的 Actions 紀錄確認。

像素檢視由各檢查者另列實際觀看的畫面；生成 PNG 不視為已觀看。服務報表 14 欄的部分日期會折成兩行，但完整值仍在安全邊界內。外部官方設計稽核工具存在詞法解析逾時，保留逾時紀錄；經既有私人修正解析器的檢查不冒充官方工具通過。正式計價、薪資、資格、定位、申報與介接仍需核定。

公開倉庫只含可公開程式、合成測試與文件。GitHub 上傳及 CI 不代表持久主機、HTTPS、正式 Portal 發布或真實營運 UAT 已完成。

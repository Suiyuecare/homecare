# 員工證照與訓練切片

本輪新增 `/certifications`、`/training` 與兩類持久化紀錄。這是獨立系統測試契約，原功能追溯仍為局部實作。

## 原介面證據與缺口

來源：`notes/employee-evidence.json` 中 `/employee/certification/:employeeId` 的「證書」及「開啟新增」兩個狀態。觀察欄位為證書／證照名稱、生效日、有效期限、證號、進修年度、課程時數（分鐘）、積分點數、備註。

本輪結構化名稱、證號、到期日與備註，另保存核發日及發證單位；核發日不推定等同原生效日。訓練以日期、分類、主辦單位及實際分鐘獨立保存。原進修年度、積分點數、附件、正式資格審查及排班資格連動仍未完成。沒有積分換算或自動判定合法資格。

## 操作契約

- 管理者及督導新增／修改／撤銷證照、新增／修改／取消訓練；居服員只讀自己的紀錄與歷程，財務無權讀寫。
- 員工必須同機構；紀錄建立後不得換成另一位員工。停用員工的紀錄保留。
- 證照核發及到期日期須有效，到期日不得早於核發日；空白到期日表示未填到期日。
- 提醒以截至日期計算，預設臺北今日。早於截至日為已到期；到期當日至30日內為即將到期；超過30日為有效。已撤銷不列為到期警示。
- 訓練分鐘為1至60000正整數。前端時數以0.25小時步進輸入，轉為整數分鐘；不產生法定積分。
- 寫入沿用CSRF、機構與角色授權、重送保護、version衝突及異動紀錄。每次修改保留版本快照，不硬刪除。
- 搜尋、員工／狀態／期限／分類篩選採伺服器分頁。姓名與篩選值不寫入瀏覽器持久儲存。
- 修改失敗保留輸入；歷程採共用唯讀dialog，支援讀取、失敗重試、關閉中止及焦點回復。

## 驗證門檻

整合驗證包含機構隔離、他人紀錄／歷程不可讀、角色拒絕、同機構外鍵、員工不可更換、到期當日與30／31日邊界、無期限與撤銷、非法日期及倒置、時數範圍、重送與版本衝突。瀏覽器驗證涵蓋兩頁新增、編輯、歷程、篩選、失敗保留及桌機1440px／手機390px的標籤、焦點與溢出。

證據將保存於 `tests/personnel.test.mjs`、`tests/personnel-e2e.mjs`、`outputs/software/personnel-qa/`。通過後只標記此獨立切片可操作，原RM-01及原證書頁維持partial。

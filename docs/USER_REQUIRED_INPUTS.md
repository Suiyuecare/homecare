# 正式功能資料與核定清單

本清單一次彙整尚缺的資料。可提供文件位置及核定人，已備妥的部分可以先交；不要在聊天或公開倉庫放密碼、簽署金鑰、完整帳號綁定或真實個案資料。測試樣本請去識別或使用合成資料。

可先建置的程式與需要核定的業務內容分開驗收。設定欄位或合成流程通過，不代表正式金額、主管機關核銷、原平台表報完整對等或正式部署完成。

## 已有決定

- 使用官方 BA／AA 清冊作為價格來源；官方碼試算保留資料来源及價格快照，不自動推定個案資格或額度。
- 薪資支援時薪制及拆帳制；實際個人費率、拆帳基數與AA處理仍須明確核定。
- 候選網址為 `homecare.suiyuecare.com`；既有DNS不等於有持久主機、HTTPS或已發布Portal。
- 背景定時工作維持停止。本次工作直接開發、合成測試與公開程式推送，正式申報、付款、外部訊息及上線各有獨立驗收。

## 收到資料後的接續順序

1. 核對格式、來源、版本與核定人，建立可以重跑的合成正反例。
2. 先補計價／額度與個人薪資規則，再接正式申報與退補結清。
3. 逐份導入核定表報並核對完整欄位、公式、輸出及權限。
4. 依核定行動及分享政策製作，完成實機與跨機構撤權驗證。
5. 在核定持久主機進行移轉、還原、Portal、容量及完整月份試點驗收，才記錄正式可用。

# 歲悅居家照顧作業系統

目前版本 **0.56.0**。這是獨立開發、使用 SQLite 保存資料的本機測試軟體，供合成資料與業務流程驗證。公開版本包含 APM CIS 共用介面與 Portal 單一登入接收端；正式持久主機、HTTPS、Portal 發布及真實公司帳號 UAT 尚待完成。本機功能仍是有限範圍，不代表任何外部平台的完整功能等價。

## 本機啟動

需要 Node.js **22.13.0 或以上**；執行伺服器沒有第三方 runtime dependency。Git clone 後進入此專案目錄，以全新的資料目錄與自行選定的可用埠啟動：

```sh
HOME_CARE_AUTH_MODE=local DATA_DIR=./data/local-synthetic PORT=4321 node src/server/index.mjs
```

`4321` 是範例埠；若被占用請換一個可用埠。預設只監聽 `127.0.0.1`。開啟 `http://127.0.0.1:4321`，首次建立測試機構與管理者，密碼至少 12 字元；可勾選載入合成示範資料。專案沒有預設密碼、預先開通帳號或私人資料庫。請只輸入合成資料，勿將正式資料放入此測試環境。

SQLite 與附件保存在 `DATA_DIR`，重新啟動不會清空資料。再次試用其他工作空間時請指定另一個全新目錄；不要刪除已有資料來取代備份或重設流程。使用 `Ctrl+C` 關閉自己啟動的程序。

## 可操作範圍

- 個案、照顧計畫、多組聯絡人、個案與證照附件；編輯保留未修改原值，衝突需要重新讀取。
- 員工、證照與期限提示、訓練紀錄、面試者登錄、服務項目與請假紀錄。
- 單班與週期排班、班表週／月閱讀、本人服務填寫、督導核閱與保存時點的計價快照。
- 既有評估表單、需求評估及督導訪視保存內容查詢、人工暫停／結案追蹤及版本歷程。
- 機構公告、本人已讀回執、查詢報表，以及四角色各自的本人事件清單、月份與年度完整閱讀。
- 機構與伺服器角色授權、CSRF、版本衝突、有限 POST 重送保護及合成備份／還原演練。

正式給付、薪資、評分、資格認定、資料移轉、申報及外部介接規則仍待核定。證照到期是提示，訓練分鐘不換算法定積分，人工事件不構成正式出勤；試算報表不能當成正式付款或申報依據。

## 檢查與測試

```sh
npm run check
npm test
```

單元與 HTTP 測試使用合成資料與隔離工作空間。真瀏覽器測試另需要安裝專案的開發依賴與 Chromium；準備與指定命令見 [測試說明](docs/TESTING.md)。公開匯出、CI 與部署須各自保存實際執行結果；原本本機開發的私人測試產物未包含在此 repository，不能當成此公開副本或目前正式網站的驗收證明。

## 公司入口與部署

Portal 模式由已驗證公司身分簽署短效憑證，本模組驗證明確身分綁定後建立自己的 session；不以 email 自動廣開角色，也不附帶真實帳號開通。接收端與開通 CLI 在本 repository，正式 Portal 簽署端與 grant 需要另外整合、核定及發布。

設定與交接步驟見 [APM CIS／Portal 部署契約](docs/APM_CIS_SSO_SCOPE.md)。主機必須持久保存 SQLite、附件及重放 nonce；不能直接把資料庫放在暫存檔案系統。正式網址、TLS、公司入口、帳號授權、備份／還原與真實 UAT 分別驗收，不能由 DNS 紀錄或本機測試推定已上線。
